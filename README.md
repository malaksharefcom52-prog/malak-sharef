## 🎮 كيفية اللعب

### البدء السريع:

1. **افتح `index.html`** في متصفح الويب (Chrome, Firefox, Safari, etc.)
2. **سجل حساب جديد** أو **ادخل** إذا كان لديك حساب بالفعل
3. **اختر شخصيتك** (أسد الصحراء أو الظل السريع)
4. **اختر المستوى** (من 1 إلى 12)
5. **ابدأ اللعب والقتال!**

### التحكم:

#### لوحة المفاتيح:
- **⬅️➡️ أو A/D** - الحركة يميناً ويساراً
- **⬆️ أو W** - القفز
- **Space** - قفز إضافي
- **E** - هجوم خاص
- **Q** - تبديل السلاح
- **Click الماوس** - إطلاق السلاح المسافة

#### جويستك PS4:
- **العصا اليسرى** - الحركة
- **X** - القفز
- **L1** - تبديل السلاح
- **R1/R2** - إطلاق النار/هجوم
